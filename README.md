# BIGSPY AI Connect — Windows Releases

Repo phân phối installer và dữ liệu cập nhật; source nằm trong repo bigspy-ai-connect.

Tải installer từ [GitHub Releases](https://github.com/bentarofficial/bigspy-ai-connect-release/releases). Ứng dụng đã cài kiểm tra nguồn này qua electron-updater. Mỗi phiên bản cần installer NSIS, file .blockmap và latest.yml được tạo cùng build. Portable chỉ dùng để thử/chạy trực tiếp; muốn cập nhật trong app hãy cài installer.

Ứng dụng lưu dữ liệu ngoài thư mục cài đặt tại %APPDATA%/bigspy-ai-connect. Nâng cấp và gỡ cài đặt giữ nguyên dữ liệu này và thư mục dự án của người dùng.

Bản preview chưa ký số, chưa tích hợp AI/Telegram; xem ghi chú từng release để biết phạm vi đã triển khai. Bản 0.1.0 chưa có updater, cần cài installer mới một lần.
